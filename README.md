# GS Point Scanner v0.2 — إدخال النقاط بالصوت في ملف Excel

## طريقة الاستخدام
1. **استيراد ملف Excel** (.xlsx) ← اختر الورقة، صف العناوين، عمود الاسم (أو اللقب + الاسم) وعمود النقطة (من «إعدادات الأعمدة»).
2. اضغط **إدخال بالصوت** وانطق النقطة: «خمسة عشر ونصف»، «حداش»، «quinze»، «15,5» …
3. راجع النقطة ثم **تأكيد** (أو قل «تأكيد»). أوامر أخرى: «السابق»، «تجاوز / غائب».
4. **الوضع التلقائي**: يحفظ النقطة فور سماعها ويستمع للتلميذ التالي مباشرة.
5. **تصدير Excel** عند الانتهاء (الزر يتلوّن إن وُجدت تعديلات غير محفوظة).

## بناء APK
### الطريقة الأسهل (بدون تثبيت شيء): GitHub Actions
ارفع المجلد إلى مستودع GitHub ← تبويب **Actions** ← **Build APK** ← **Run workflow** ← حمّل `GS_Point_Scanner-apk` من Artifacts.

### على جهازك
ثبّت Flutter + Android Studio ثم: `build_apk.bat` (Windows) أو `./build_apk.sh`.
الناتج: `build/app/outputs/flutter-apk/app-release.apk`.
(السكربت ينشئ مجلد android تلقائياً وينسخ `android_overrides/AndroidManifest.xml` الذي يحوي إذن الميكروفون وخدمة التعرف الصوتي — بدونه لا يعمل الصوت.)

## ما الذي تحسّن عن النسخة الأولى
- **إصلاح خطأ جوهري**: «خمسة عشر» كانت تُقرأ 5 (وكذلك 11–19)؛ المحلّل الجديد (`number_parser.dart`) يفهم الفصحى والدارجة الجزائرية (حداش، طناش، تلتاش…) والفرنسية والأرقام العربية/الهندية، والكسور (ونصف، وربع، فاصلة).
- ملف android كان ناقصاً (لا إذن ميكروفون) ← أضيف مع سكربتات البناء.
- دعم لقب + اسم في عمودين، واختيار الورقة عند تعدد الأوراق.
- تخطي الصفوف الفارغة تلقائياً، وإظهار النقطة الحالية عند الرجوع للتعديل.
- شريط تقدّم، وقائمة تلاميذ للقفز لأي تلميذ، وأوامر صوتية، ووضع تلقائي.
- اختيار لغة ar-DZ تلقائياً إن توفرت وإلا أقرب عربية.
- واجهة RTL قابلة للتمرير + وضع داكن، والنقاط الصحيحة تُكتب أعداداً (15 لا 15.0).
